LiouScope -- Beyond the Liouvillian Gap
=======================================

LiouScope is a multi-diagnostic relaxation analysis framework for
finite-dimensional time-homogeneous Markovian open quantum lattice systems
(GKSL / QMS). It quantifies when and why the Liouvillian gap fails as a
relaxation-time predictor.

This documentation is generated from the in-source docstrings plus the
hand-written reference files in :ref:`reference`.
